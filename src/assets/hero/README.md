# Hero stickers

Put your own sticker images in this folder (`.png`, `.jpg`, `.webp` or `.svg`) and the
floating stickers on the home page will use them automatically — no code changes needed.

- Files are shown in filename order, so name them like `1-audi.png`, `2-gt86.png`,
  `3-drpepper.png`, `4-vinyl.png`, `5-dragon.png` to control placement.
- The first five images are used.
- Images with transparent backgrounds look best (the layout floats them freely).
- If this folder has no images, the home page falls back to the built-in SVG placeholders.
